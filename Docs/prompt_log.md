# 주요 프롬프트 기록

`gosthunter`(귀신게임) 개발 중 나온 지시와 질문을 시간순으로 정리했다. 원문 그대로다.

`[수정]`은 구현 요청, `[질문]`은 원인 파악이나 개념 확인.

**1. [수정]**
> 게임 시작도 안했는데 플레이시점이 활성화되서 게임시작을 못누름. 대기방은 그냥 ui 창으로 하고 게임 시작하면 플레이 시점 나오게 하자

**2. [수정]**
> 추가로 space bar누르면 점프되게 하자
> 문제 1. 도구와 상호작용이 안됨. 도구 가까이 가면 줍기(E) 이렇게 도구 옆에 뜨고 E 키를 누르면 수집되면서 화면 아래 중앙에 아이템 창에 도구가 들어와야 함.
> 문제2. 귀신 입장에서도 퇴마사가 보이지 않음.
> 문제3. 메인 하우스 에셋 zip을 풀어서 넣어놨고, 퇴마사와 귀신 에셋도 넣어놨는데 적용되면 좋겠음.

**3. [수정]**

> 1. 줍는 키를 F 키로 지정
> 2. 문열고 닫는 키도 F키로 지정
> 3. 물체와 상호작용하거나 귀신이 퇴마사와 상호작용할 때 '스킬(ctrl)', '줍기(F)'와 같은 설명이 근처에 표시되어야 함

**4. [수정]**
> 문제 1. 문열리는 모션이 없음.

> 문제 3. 조사 단계에서 귀신이 움직일 수 있음.
> 전체적으로 게임 시나리오가 반영이 안된거 같아서 다시 읽고 구현해야 할듯
