# 주요 프롬프트 기록

`gosthunter`(귀신게임) 개발 중 나온 지시와 질문을 시간순으로 정리했다. 원문 그대로다.

`[수정]`은 구현 요청, `[질문]`은 원인 파악이나 개념 확인.

**1. [수정]**
> 게임 시작도 안했는데 플레이시점이 활성화되서 게임시작을 못누름. 대기방은 그냥 ui 창으로 하고 게임 시작하면 플레이 시점 나오게 하자

**2. [수정]**
> 추가로 space bar누르면 점프되게 하자
> 문제 1. 도구와 상호작용이 안됨. 도구 가까이 가면 줍기(E) 이렇게 도구 옆에 뜨고 E 키를 누르면 수집되면서 화면 아래 중앙에 아이템 창에 도구가 들어와야 함.
> 문제2. 귀신 입장에서도 퇴마사가 보이지 않음.
> 문제3. 메인 하우스 에셋 zip을 풀어서 넣어놨고, 퇴마사와 귀신 에셋도 넣어놨는데 적용되면 좋겠음.

**3. [수정]**

> 1. 줍는 키를 F 키로 지정
> 2. 문열고 닫는 키도 F키로 지정
> 3. 물체와 상호작용하거나 귀신이 퇴마사와 상호작용할 때 '스킬(ctrl)', '줍기(F)'와 같은 설명이 근처에 표시되어야 함

**4. [수정]**
> 문제 1. 문열리는 모션이 없음.
> 문제 2. 귀신이 투명이아님. 퇴마사 입장에서 귀신이 보임
> 문제 3. 조사 단계에서 귀신이 움직일 수 있음.
> 전체적으로 게임 시나리오가 반영이 안된거 같아서 다시 읽고 구현해야 할듯

> 'f'키로 도구를 주울 수 있음.
> 'g' 키로 지니고 있던 도구를 다시 바닥에 놓을 수 있음

> 제단에 도구를 바쳐도 사라지지 않음. f키를 누르면 제단의 바구니 안에 도구가 들어가고, 다시 f 키를 눌러 회수할 수도 있음. 제단에 도구 3종류가 들어가면 제단 기능 발동. 옳은 조합이면 그대로 승리하고, 틀리면 무작위 한명이 죽고 제단에 바쳐진 도구는 회수가 가능함.

**130. [수정]**
> 게임 구조를 좀 더 바꿀거야. 기존에는 은신-조사-사냥 3 단계였지만 아래와 같이 바꿀거야.
>
> 단계: 1. (은신 - 조사) <- 사이클로 이루어짐  2. 사냥
> 게임 시작시 은신(귀신이 숨는 단계)로 시작해서 은신을 완료하면 조사 단계로 넘어가서 퇴마사들이 조사를 시작함
> 이 조사에는 제한시간이 존재한다. 이 제한시간 안에 탐지도구를 사용해 귀신의 약점을 하나라도 밝혀내지(위치를 찾지)못하면 귀신은 사냥 단계로 넘어가게되고 귀신은 사냥을 시작한다.
> 조사 시간 내에 귀신을 찾게(탐지하게) 되면 다시 은신 단계로 넘어가며 귀신은 다시 숨을 곳을 옮기게된다.
> 숨을 곳을 옮기고나면 다시 조사 단계가 시작되고 이때 다시 돌아온 조사단계에서는 조사 시간을 다시 회복한다
> 이런식으로 은신->조사->은신->조사가 반복되고 만약 조사 단계에서 시간 제한을 넘기게 되면 사냥으로 넘어가게 되는 방식
> 한번 탐지에 성공한 퇴마 도구로는 다시 탐지가 불가능하다.
> 세번째 조사시간에서도 탐지에 성공한다면 약점인 3개의 탐지도구를 모두 찾은 것이므로 은신단계로 넘어가지 않고 퇴마사의 승리로 끝난다.
> 조사시간에 탐지에 성공한다면 어떤 탐지도구로 탐지에 성공했는지 모든 플레이어가 알수 있게 화면 중상단에 메시지를 띄운다.
>
> 제단은 조사시간이라면 언제든지 사용할 수 있으며, 제단에 약점인 올바른 탐지도구 3종을 넣었다면 승리로 게임이 끝나지만, 틀린 조합을 넣었다면 퇴마사 중 무작위 한명이 죽게된다. 때문에 제단은 신중하게 사용해야한다.
> 그리고 만약 귀신이 퇴마사를 공격해 영혼게이지를 모두 채우면 실체화하며 바로 사냥단계로 들어가게된다.
