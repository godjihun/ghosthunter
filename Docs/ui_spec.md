# UI / UX 명세서

`gosthunter`(귀신게임) — 화면별 구성·버튼·상호작용

기능 정의는 [functional_spec.md](functional_spec.md), 게임 규칙은 [ghost_game_scenario.md](ghost_game_scenario.md)를 본다.
이 문서는 **"어떤 화면에 무엇이 있고 무엇을 누를 수 있는가"**만 다룬다.

**상태 표기**: ✅ 구현됨 / 🟡 임시 구현(IMGUI) / ⬜ 미구현

---

## 0. 먼저 읽을 것 — 이 게임 UI의 제1원칙

> **UI가 귀신 위치를 알려주면 게임이 끝난다.**

일반적인 게임에서는 친절한 UI가 미덕이지만, 이 게임에서는 **친절함이 곧 정보 유출**이다. 아래는 협상 불가다.

| 금지 | 이유 |
|---|---|
| 미니맵에 귀신 표시 | 위치가 곧 게임의 비밀 |
| 귀신 방향 표시기·거리 인디케이터 | 위 동일 |
| 퇴마사 화면에 약점 도구 표시 | 귀신만 아는 정보 |
| 탐지 결과를 팀에 자동 공유 | 말로 전하는 것이 플레이의 일부 |
| **탐지 성공·실패의 표시 시간·연출 차이** | **연출 길이 자체가 단서가 된다** |
| 귀신이 말할 때 발화 표시(스피커 아이콘 등) | 귀신은 발화 자체가 차단됨 (VC-02) |

**반대로 공개해도 안전한 것**: 누가 귀신인지(정체는 안 숨김), 제단 현황, 현실화 게이지, 남은 시간.

## 1. 화면 흐름

```
[S1] 시작 화면
      ├─ 방 만들기 ─▶ [S2] 방 개설 ─┐
      └─ 참가하기  ─▶ [S3] 방 참가 ─┤
                                     ▼
                              [S4] 대기방
                                     │ 방장이 시작
                                     ▼
                    ┌─────── [S5] 인게임 ───────┐
                    │  S5-A 공통 HUD            │
                    │  S5-B 퇴마사 / S5-C 귀신  │
                    │  S5-D 은신 안내           │
                    │  S5-E 이모트 휠 (오버레이) │
                    └───────────┬───────────────┘
                          사망 │        승패 확정
                               ▼              ▼
                        [S6] 관전 화면   [S7] 결과 화면

[S0] 로딩       — 최초 진입 시
[S8] 설정 오버레이 — 어디서든 ESC
```

## 2. 화면별 명세

### S0. 로딩 화면 ⬜

WebGL은 첫 진입에 리소스를 내려받는다. **빈 화면으로 두면 이탈한다.**

| 요소 | 내용 |
|---|---|
| 진행률 | 퍼센트 또는 바. 멈춘 것처럼 보이지 않게 |
| 게임 타이틀 | |
| 조작 안내 | 기다리는 동안 읽을거리 |

⚠️ **브라우저 정책상 사용자가 한 번 클릭하기 전에는 소리가 나지 않는다.** 로딩이 끝나면 **"클릭해서 시작"** 같은 진입 버튼을 반드시 한 번 거치게 한다. 이걸 빠뜨리면 게임 내내 무음이고 원인도 안 보인다.

---

### S1. 시작 화면 ⬜ (현재 S1~S4가 한 패널로 합쳐진 임시 UI 🟡)

| 요소 | 종류 | 동작 |
|---|---|---|
| 닉네임 | 텍스트 입력 | 최대 12자 권장. 관전·음성에서 쓰인다 |
| **방 만들기** | 버튼 | → S2 |
| **참가하기** | 버튼 | → S3 |
| 설정 | 버튼 | → S8 |

- 닉네임이 비어 있으면 두 버튼을 **비활성화**한다.
- 마우스 커서는 **잠금 해제** 상태다.

---

### S2. 방 개설 ⬜

| 요소 | 종류 | 기본값 |
|---|---|---|
| 방 이름 | 텍스트 입력 | `{닉네임}의 방` |
| 인원 제한 | 슬라이더 / 드롭다운 | 5 (최대 5) |
| 비밀번호 | 텍스트 입력 (선택) | 없음 |
| **만들기** | 버튼 | → S4 (방장으로) |
| 뒤로 | 버튼 | → S1 |

- **인원 하한을 두지 않는다.** 심사자가 혼자 2탭으로 확인할 수 있어야 한다.
- 생성 실패 시 패널 안에 사유를 표시하고 **입력값은 지우지 않는다.**

---

### S3. 방 참가 ⬜

| 요소 | 종류 | 동작 |
|---|---|---|
| 참가 코드 | 텍스트 입력 | 대소문자 구분 없이 처리 |
| **참가** | 버튼 | → S4 |
| 뒤로 | 버튼 | → S1 |

- **링크에 코드가 들어 있으면**(`?room=ABCD`) 이 화면을 건너뛰고 바로 참가한다.
- 실패 시 사유를 구분해 보여준다: 없는 방 / 정원 초과 / 비밀번호 불일치 / 이미 시작됨.

⚠️ **현재 구현된 임시 UI의 실패 처리를 참고할 것.** "호스트가 없는데 클라이언트로 접속"을 시도하면 소켓이 물린 채 남아 이후 방 생성까지 실패했던 이력이 있다. 실패 시 **연결 자원을 반드시 회수**하고, 사용자에게는 다음 행동(방을 만드시겠습니까?)을 제시한다.

---

### S4. 대기방 🟡

| 영역 | 요소 | 비고 |
|---|---|---|
| 상단 | 방 이름, **참가 코드**, 복사 버튼 | 코드 공유가 이 화면의 주 목적 |
| 좌측 | 플레이어 목록 (닉네임, 방장 표시, 준비 상태) | |
| 우측 | **밸런스 파라미터 8종** | 방장만 조작 가능, 나머지는 읽기 전용 |
| 하단 | **게임 시작**(방장) / 닫기 | 실제 구현은 대기방 안 '게임 설정' 단말(F)의 IMGUI 창이다 |

**밸런스 파라미터** (시나리오 6번)

| 항목 | 범위 예시 | 기본 |
|---|---|---|
| 귀신 은신 시간 | 10~90초 | 30초 |
| 조사 제한시간 | 2~15분 | 8분 |
| 공포스킬 쿨타임 | 5~90초 | 30초 |
| 재은신 시간 | 5~40초 | 15초 |
| 도구 탐지 사거리 | 5~60m | 50m |
| **흡수 1회당 게이지** | 5~50% | 20% |
| 도구 쿨타임 | 5~60초 | 20초 |
| 사냥 시간 | 30~180초 (5단위) | 60초 |

- **쿨타임과 게이지 상승량은 붙여서 배치한다.** 둘이 곱해져 최소 현실화 시간을 만들므로 따로 보면 감이 안 온다. `현재 설정: 최소 2분`처럼 **계산 결과를 실시간으로 보여주는 것**을 권장한다.
- 시작 버튼은 **2인 이상**일 때만 활성화.
- 커서 잠금 해제 상태.

### S5-A. 인게임 — 공통 HUD ✅

| 위치 | 요소 | 상태 |
|---|---|---|
| 좌상단 | 현재 단계 (은신 / 조사 / 사냥) | ✅ |
| 좌상단 | 남은 시간 | ✅ |
| 좌상단 | 내 진영 | ✅ |
| **상단 중앙** | **현실화 게이지 (0~100%)** | ⬜ |
| 화면 중앙 | 조준점 | ✅ |
| 하단 중앙 | 상호작용 프롬프트 (`줍기 (F)` 등) | ✅ |

**현실화 게이지 표시 규칙**
- **양 진영 모두에게 보인다.** 위치 정보가 없으므로 안전하다.
- 귀신에게는 진행도, 퇴마사에게는 압박이다. **차오르는 순간 눈에 띄게** 반응시킬 것(색 변화·짧은 펄스).
- 사냥 단계에 진입하면 게이지는 사라지고 **사냥 남은 시간**으로 대체된다.

**커서는 게임 중 잠긴다.** 로비·결과 화면에서만 풀린다 — 이 전환은 한 곳에서만 관리해야 "커서는 잠겼는데 UI는 떠 있는" 상태가 안 생긴다.

---

### S5-B. 인게임 — 퇴마사 HUD ✅

| 위치 | 요소 | 상호작용 | 상태 |
|---|---|---|---|
| 하단 중앙 | **소지 도구 슬롯 (4칸)** | `1`~`4` 선택, 남은 쿨타임·`사용됨` 표시 | ✅ |
| 발밑 (월드) | ~~탐지 반경 원~~ | 시야 기반으로 바뀌어 제거 | ❌ |
| 화면 중앙 | **탐지 결과** | 좌클릭 후 1.5초 | ✅ |
| 우측 | **밝혀낸 약점 (3칸) + 제단 현황 (3칸)** | 표시 전용, 전원 공개 | ✅ |
| 중상단 | **약점 발견 공지** | 탐지 성공 시 전원에게 | ✅ |
| 대상 근처 | 상호작용 프롬프트 | `F` | ✅ |

**⚠️ 탐지 결과 표시 — 이 게임에서 가장 민감한 UI**

```
성공: "탐지됨 — 이 도구는 약점이다"
실패: "반응 없음"
```

- **표시 위치·크기·지속 시간(1.5초)·애니메이션이 완전히 같아야 한다.**
- 실패를 더 빨리 지우거나 연출을 생략하면 **연출 길이 자체가 정보**가 되어 시나리오 3-2의 모호성이 깨진다.
- 결과는 **사용한 본인 화면에만** 뜬다.

**제단 현황**은 종류만 보여준다. 누가 넣었는지는 표시하지 않는다.

**소지 슬롯은 항상 4칸을 다 그린다.** 빈 칸이 보여야 "몇 개까지 들 수 있는지"와
"1~4로 고른다"가 눈에 익는다. 고른 칸은 테두리를 한 겹 더 그려 구분하며,
**빈 칸을 고른 상태도 표시해야 한다** — 줍기와 제단 회수가 그 상태에서만 성립하기 때문이다.

칸 아래 문구는 상황에 따라 바뀐다:

```
조사 중 → 1~4 선택  좌클릭 사용  G 내려놓기
은신 중 → 은신 중 — 도구를 쓸 수 없다  (1~4 선택 / G 내려놓기)
```

**약점 발견 공지는 탐지 결과와 다르다.** 탐지 *실패*는 본인만 보지만,
*성공*은 어떤 도구였는지 **전원**이 화면 중상단에서 본다 — 팀이 후보를 좁히고
귀신이 남은 약점 수를 가늠하는 근거가 된다.

### S5-C. 인게임 — 귀신 HUD ✅

| 위치 | 요소 | 상호작용 | 상태 |
|---|---|---|---|
| 좌상단 | **내 약점 3종** | 표시 전용. **귀신 화면에만** | ✅ |
| 하단 중앙 | 영혼/본체 상태 + `Q` 안내 | 조사 단계에만 표시 | ✅ |
| 월드 | **본체 위치 표식 + 거리** | 영혼 상태에만 | ✅ |
| 화면 중앙 | 공포스킬 프롬프트 / 쿨타임 | `Ctrl` | ✅ |

- 본체 표식이 화면 밖이면 **거리만** 표시한다.
- 사냥 단계에서는 프롬프트가 `처형 (Ctrl)`로 바뀐다.
- **영혼 분리 안내는 조사 단계에만 띄운다.** 다른 단계에서 띄우면 `Q`를 눌러도 반응이 없어 고장으로 오해한다.

**탐지 페널티 알림** (기능 명세서 §3-4) ⬜

탐지당하면 영혼이 강제로 끌려오고 15초간 본체가 자유로워진다. **이 15초가 새 은신처로 옮길 유일한 기회**이므로, 남은 시간을 모르면 기회를 놓친다.

| 요소 | 내용 |
|---|---|
| 경고 배너 | "탐지당했다 — 영혼이 복귀했다" |
| **카운트다운** | 남은 무효화 시간. **"지금 움직이라"는 신호** |
| 상태 표시 | 그 동안 "본체 이동 가능" |

- **귀신 화면에만 뜬다.** 퇴마사는 자기 탐지가 성공한 것만 알 뿐, 귀신이 페널티 중이라는 사실은 모른다.
- 타이머가 끝나면 본체가 다시 고정되므로 **끝나는 순간을 분명히** 알린다.

### S5-D. 은신 단계 안내 ✅

은신은 판 시작에 한 번만 오는 게 아니라, **탐지에 성공할 때마다 돌아온다**(재은신).
둘은 퇴마사 쪽 규칙이 달라서 안내도 갈라야 한다.

| | 첫 은신 | 재은신 |
|---|---|---|
| 퇴마사 | **움직일 수 없다** | 자유롭게 이동·줍기 |
| 도구 | — | **무효화 (탐지 불가)** |
| 안내 (퇴마사) | "귀신이 숨고 있습니다…" | "귀신이 자리를 옮기고 있습니다…" |
| 안내 (귀신) | "몸을 숨기세요…" | "들켰습니다… 다른 곳으로 자리를 옮기세요." |

첫 은신에서 이유를 알려주지 않으면 게임이 멈춘 줄 안다. 재은신에서는 반대로
**움직일 수 있다는 것과 도구만 안 된다는 것**을 알려야 한다 — 좌클릭이 먹통이면
고장으로 오해하기 때문에, 소지 슬롯 아래 문구가 그 역할을 한다(S5-B).

### S5-E. 이모트 휠 (오버레이) ✅

| 조작 | 동작 |
|---|---|
| `Tab` 누르고 있기 | 휠 열림 |
| 마우스 이동 | 방향으로 항목 선택 |
| **좌클릭** | 선택 확정 → 3인칭 전환 후 재생 |
| `Tab` 떼기 | 취소 |

- 휠이 열린 동안 **시점 회전과 도구 사용을 막는다.** 마우스가 선택에 쓰이므로 화면까지 돌면 고를 수 없고, 좌클릭이 도구 사용으로 새면 안 된다.
- 항목 수는 코드의 배열 길이를 따라간다 — **UI에 개수를 하드코딩하지 말 것.**
- 귀신은 **사냥 단계에만** 쓸 수 있다.

### S6. 관전 화면 ⬜

**사망 시에만** 진입한다. 흡수는 사망이 아니므로 넘어가지 않는다.

| 위치 | 요소 | 상호작용 |
|---|---|---|
| 전체 | 관전 대상의 **3인칭 뒤** 시점 | |
| 하단 중앙 | **관전 중인 닉네임** | |
| 닉네임 좌우 | **◀ ▶ 화살표** | 클릭 또는 `A`/`D` |
| 상단 | "사망 — 관전 중" | |
| 우하단 | 사망자 음성 채널 표시 | 말하는 사람 강조 |

- 대상은 **생존한 퇴마사만**이다. **귀신은 관전 대상이 될 수 없다** — 관전으로 위치가 새면 게임이 무너진다.
- 관전 대상이 죽으면 **자동으로 다음 대상**으로 넘어간다.
- 관전할 대상이 없으면(전멸 직전) 안내 문구를 띄우고 곧 결과 화면으로 간다.
- 1인칭을 그대로 물려받지 않는다. 남의 시점 흔들림을 계속 보면 멀미가 난다.

### S7. 결과 화면 ✅

| 요소 | 내용 | 상태 |
|---|---|---|
| 승패 | 퇴마사 승리 / 귀신 승리 | ✅ |
| **약점 3종 공개** | 이제야 전원에게 공개 | ✅ |
| **대기방으로 돌아가기** | 방장만 실행 | ✅ |
| 나가기 | 접속 종료 | ✅ |

- 커서 잠금 해제.
- 방장이 아닌 사람에게는 "방장이 돌아가기를 누르는 중"을 표시해 **버튼이 없는 이유**를 알린다.

### S8. 설정 오버레이 ⬜

`ESC`로 어디서든 연다. **음성이 들어오면서 필수가 됐다.**

| 항목 | 종류 |
|---|---|
| 마이크 입력 장치 | 드롭다운 |
| 마이크 감도 / 음소거 | 슬라이더 + 토글 |
| 발화 방식 | 상시 / 푸시투토크 선택 |
| 스피커 볼륨 (게임 / 음성 분리) | 슬라이더 2개 |
| 마우스 감도 | 슬라이더 |
| 조작 안내 | 표 |
| 나가기 | 버튼 |

- 인게임에서 열면 **커서를 풀고, 열려 있는 동안 조작을 막는다.**
- ⚠️ **멀티플레이라 게임은 멈추지 않는다.** 설정을 여는 동안에도 귀신은 다가온다 — "일시정지"라고 부르지 말 것.

## 3. 음성 채팅 UI ⬜

| 요소 | 위치 | 규칙 |
|---|---|---|
| 내 마이크 상태 | 좌하단 | 켜짐/꺼짐/말하는 중 |
| 발화자 표시 | 해당 캐릭터 위 또는 목록 | **생존 퇴마사만** |
| 사망자 채널 표시 | 관전 화면 우하단 | 사망자에게만 보임 |

**⚠️ 귀신에게는 마이크 UI를 아예 띄우지 않는다.** 귀신은 발화가 차단돼 있다(VC-02). 마이크 버튼이 보이는데 안 눌리면 고장으로 오해하므로, **"듣기 전용"임을 명시**하는 편이 낫다.

**거리 감쇠를 눈으로 알 수 있게 한다.** 목소리가 작아지는 게 거리 때문인지 상대가 작게 말해서인지 구분되지 않으면 답답하다. 발화자 표시의 **투명도나 크기를 거리에 연동**하는 정도면 충분하다.

3. **이모트 휠 항목 수를 하드코딩하지 말 것** — 배열 길이를 따라간다
