# 귀신게임 시나리오 정리

비대칭 멀티플레이 공포/추리 게임. 1명의 귀신 vs 다수의 퇴마사가 한 저택에서 대결한다.

---

## 1. 핵심 컨셉트 요약

- **비대칭 대결**: 소수(귀신 1) 대 다수(퇴마사)의 숨바꼭질 + 추리 게임.
- **은닉 정보**: 귀신은 본체·영혼 모두 기본 투명. 어떤 도구가 귀신의 약점인지도 숨겨져 있다.
- **퇴마사의 목표**: 맵에 숨겨진 도구를 찾아 사용해보며 귀신의 약점 도구 3종을 추리 → 지하 제단에 하나씩 던져 헌납.
- **귀신의 목표**: 약점을 들키지 않고 버티며 공포스킬로 영혼을 흡수해 **현실화 게이지**를 채운다. 게이지 100% 또는 시간 종료 시 현실화(투명 해제)하여 사냥.
- **긴장의 축**: 퇴마사는 "틀린 조합 = 동료 사망"이라는 리스크를 안고 추리하고, 귀신은 위치와 약점을 숨기며 심리전을 건다.

---

## 2. 진영 구성

### 귀신 (1명)
- 본체와 영혼을 분리할 수 있으며, **둘 다 기본적으로 투명**.
- **누가 귀신인지는 전원에게 공개된다.** 숨기는 것은 정체가 아니라 **위치**다 — 이 게임은 "누가 귀신이냐"를 맞히는 게임이 아니라 "귀신이 어디 있고 약점이 뭐냐"를 찾는 게임이다.
- **영혼 상태로 이동**하며 퇴마사를 찾아다니고 **공포스킬**로 영혼을 흡수한다.
- **영혼도 벽·바닥을 통과할 수 없다.** 퇴마사와 마찬가지로 통로와 계단으로 돌아가야 한다 — 통과가 가능하면 공포스킬을 너무 쉽게 걸 수 있어 밸런스가 무너진다.
- 단 **문은 통과할 수 있다.** 문을 못 뚫으면 영혼이 문을 열어야 하는데, 문이 저절로 열리는 게 보이면 위치가 그대로 노출되기 때문이다.
- 약점 도구에 본체가 탐지되면 페널티(영혼 강제 복귀, 재은신)를 받는다.
- 현실화 이후에는 걷기 4 m/s, **Shift 달리기 8 m/s**(퇴마사의 2배)로 사냥한다.

### 퇴마사 (다수)
- 맵 곳곳(서랍, 수납장, 탁자 아래 등)에 숨겨진 도구를 수집한다.
- **동시에 최대 4개까지 소지**한다. 칸은 고정이라 `1`~`4`로 고른 칸에 넣고 빼고 쓴다.
- 도구를 사용해 귀신의 약점 여부를 탐지하고, 약점이라 추정되는 도구를 지하 제단에 가져가 던져 넣는다.
- 협력이 핵심이나, **제단에 틀린 도구 3종이 채워지면 동료 중 1명이 사망**하는 리스크를 공유한다.

## 3. 핵심 시스템

### 3-1. 도구 시스템
- **도구 종류 6개**(카메라 / 십자가 / 성서 / 성수 / 탐지기 / 향초). 그중 **귀신의 약점은 3종류**.
- **종류당 정확히 1개씩, 저택 전체에 6개**만 무작위로 놓인다(서랍, 수납장, 탁자 아래 등).
- **도구는 소모되지 않는다.** 쓰면 사라지는 대신 **쿨타임**이 돈다.
- **쿨타임은 그때 손에 들고 있던 도구 전부**에 함께 걸린다. 혼자 여러 개를 쥐고
  번갈아 쓰며 탐지를 독점하지 못하게 하기 위한 것이고, 결과적으로 **나눠 들수록
  팀 전체의 탐지 빈도가 올라간다.**
- **쿨타임은 사람이 아니라 도구를 따라간다.** 바닥에 버리든, 남이 줍든, 제단에
  들어갔다 나오든 이어진다 — 넘기고 새로 받는 식으로 우회할 수 없다.
- **소지는 고정 4칸.** `1`~`4`로 칸을 고르고, 고른 칸을 기준으로 줍고(`F`) 내려놓고(`G`) 쓴다.
  빈 칸도 고를 수 있고, 그 상태가 곧 맨손이다.
- **한 번 탐지에 성공한 도구는 다시 쓸 수 없다** (3-2 참고).

### 3-2. 탐지 시스템

**시야 기반이다.** 도구를 쓴 **그 순간 화면 안에 귀신 본체가 있어야** 탐지된다.
본체는 투명해서 보이지 않지만, 겨눈 방향에 실제로 있었다면 잡힌다.

성립 조건 세 가지를 모두 만족해야 한다:

| | |
|---|---|
| **화면 안** | 좌우뿐 아니라 **상하도** 본다. 등 뒤는 당연히 안 된다 |
| **사거리 안** | 기본 50m (설정 가능) |
| **시선이 안 막힘** | 벽이나 닫힌 문 너머는 탐지되지 않는다 |

- 귀신이 있을 만한 **방향**을 겨누고 도구를 쓴다. 예전처럼 가까이 가서 아무 데나 쓰는 것으로는 안 된다.
- **탐지 안 됨** = 그 방향에 귀신이 없었거나 / 약점 도구가 아님 (구분 불가).
- **탐지 됨** = 그 도구가 **약점 도구이며 겨눈 방향에 귀신이 있었음** 확정.
- 즉 "탐지 실패"는 두 가지 가능성이 겹쳐 있어 추리가 필요하다.
- **탐지 실패는 도구를 사용한 본인만 안다.** 자동으로 팀에 공유되지 않는다 — 알아낸 사람이 음성이나 채팅으로 직접 전파해야 한다. 정보 전달 자체가 플레이의 일부다.

**탐지에 성공하면 판이 되감긴다.**

- 그 도구가 약점이었다는 사실이 **전원에게 공개**된다. 화면 중상단에 어떤 도구였는지 뜬다.
- 귀신은 **영혼 강제 복귀 + 도구 무효화**를 당하고 **은신 단계(재은신)** 로 넘어간다 (3-5).
- **그 도구로는 두 번 다시 탐지할 수 없다.** 허용하면 같은 도구로 사이클을 무한히 돌려
  게임이 끝나지 않는다. 남은 후보를 좁히는 것이 조사의 본체가 된다.
- **세 번째 성공 = 약점 3종을 모두 밝혀낸 것**이므로 제단을 거치지 않고 그대로 퇴마사 승리다.

### 3-3. 제단 시스템
- 조합 과정 없이, 약점이라 추정되는 도구를 퇴마사가 **지하 제단에 직접 하나씩 던져 넣는다**.
- 제단에 던져 넣은 도구는 **화면 우측 UI에 종류가 표시**되어, 현재 제단에 어떤 도구들이 헌납되어 있는지 전원이 확인할 수 있다.
- **도구는 제단에서도 소모되지 않는다.** `F`로 올려놓고, 빈 칸을 고른 뒤 `F`를 다시
  누르면 **회수**한다. 종류당 하나뿐이라 없애버리면 그 도구가 판에서 영영 사라지기 때문이다.
- 제단에 **서로 다른 도구 3종류**가 채워지면 판정:
  - **올바른 3종** (귀신의 실제 약점과 일치) → 퇴마사 승리.
  - **틀린 조합** (하나라도 약점이 아님) → 퇴마사 중 **무작위 1명 사망**. 게임은 계속되고,
    **올려둔 도구는 그대로 남아 회수할 수 있다.** 같은 조합으로 다시 판정되지는 않는다.
- 제단은 **조사 단계 내내** 쓸 수 있다. 오답의 대가가 사람 목숨이라 신중해야 한다.

### 3-4. 공포스킬 (영혼 흡수) — 현실화 게이지

- 영혼 상태에서 퇴마사에게 사용. **한 번에 1명**에게만 적용, **쿨타임** 존재(설정 가능).
- **사거리는 밀착 거리다.** 어몽어스에서 칼로 찌르는 것처럼, 대상 바로 옆에 붙었을 때만 스킬이 활성화되어 사용할 수 있다. 멀리서 저격하듯 쓸 수 없다.
- **벽·문 너머로는 걸 수 없다.** 사이가 막혀 있으면 밀착 거리 안이어도 실패한다 — 영혼이 문을 통과할 수 있더라도, 실제로 통과해서 같은 공간에 들어와야 흡수할 수 있다.
- **흡수당한 본인에게는 공포 연출이 나온다.** 흡수 사실을 알게 되며, 밀착당했다는 공포를 전달하는 것이 이 스킬의 이름값이다.
- **흡수는 퇴마사를 죽이는 것이 아니다.** 흡수당한 퇴마사는 그대로 계속 플레이한다. 도구를 줍고, 탐지하고, 제단에 헌납할 수 있다. 퇴마사를 실제로 죽이는 것은 제단 오답(3-3)과 사냥 단계(5번)뿐이다.

**흡수 성공 = 현실화 게이지 충전.**

- 게이지는 **0%에서 시작해 100%가 되면 귀신이 현실화**된다.
- 흡수 1회당 정해진 양만큼 오른다(설정 가능).
- **같은 퇴마사를 몇 번이든 다시 흡수할 수 있다.** 한 사람만 반복해서 노려도 게이지는 똑같이 찬다.
  - 그래서 **혼자 다니는 퇴마사가 위험하다.** 뭉쳐 다니면 안전하지만 도구 수색 효율이 떨어진다 — 이 딜레마가 퇴마사 쪽 긴장의 축이다.
  - 유일한 제동 장치는 **쿨타임**이다. 쿨타임이 곧 현실화까지의 최소 시간을 결정하므로 밸런스에서 가장 민감한 값이다.
- 게이지는 **인원수와 무관**하다. 그래서 제단 오답으로 누가 죽어도 현실화 조건이 깨지지 않는다.
- **탐지당해도 게이지는 줄지 않는다.** 탐지의 대가는 게이지가 아니라 강제 복귀와 재은신 시간이다(3-5).
- 게이지 현황은 **양 진영 모두에게 공개**된다. 귀신에게는 진행도이고, 퇴마사에게는 "현실화가 얼마나 임박했는가"라는 압박이다. 게이지는 **위치 정보를 담지 않으므로** 공개해도 은닉이 깨지지 않는다.

### 3-5. 귀신 탐지 페널티 시스템
영혼 이동 중 약점 도구로 본체가 탐지되면:
- 영혼이 **본체로 강제 복귀**.
- 일정 시간 **'도구 무효화'** 적용(이 동안 도구로 탐지 불가).
- 그 시간 동안 본체가 **다른 은신처로 이동** 가능.
- **현실화 게이지는 그대로 유지된다.**

**이 유예가 별도 단계(은신)로 떨어져 나와 있다.** 예전에는 조사 시간을 갉아먹으며
진행됐지만, 지금은 판이 은신 단계로 되감기고 그동안 귀신이 자리를 옮긴다.
- **퇴마사는 재은신 중에도 계속 움직인다.** 얼려두면 판이 멈추기 때문이다.
  귀신에게 주는 유예는 "퇴마사 정지"가 아니라 **도구 무효화**로 보장된다.
- 은신이 끝나면 조사 시간이 **가득 채워져** 다시 시작한다. 이전 회차에 얼마가 남았든
  상관없다 — 찾아내면 시간을 번다는 것이 퇴마사 쪽의 유일한 시간 자원이다.
- 첫 은신만 예외적으로 퇴마사를 대기지점에 묶는다 (미리 도구를 주워두면 은신의 의미가 없다).

### 3-6. 관전 시스템
- **사망한** 퇴마사는 게임에서 빠지지 않고 **생존한 퇴마사를 관전**한다. 흡수당한 것만으로는 관전으로 넘어가지 않는다 (3-4 — 흡수는 죽음이 아니다).
- 카메라는 대상 퇴마사의 **살짝 뒤 3인칭** 시점이다. 1인칭을 그대로 물려받으면 남의 시점 흔들림을 계속 봐야 해서 멀미가 난다.
- 화면 **아래 중앙에 관전 중인 퇴마사의 닉네임**이 표시되고, 그 **좌우의 화살표로 대상을 변경**한다.
- 관전 대상은 **생존한 퇴마사만**이다. 귀신은 관전할 수 없다 — 관전으로 귀신 위치가 새면 게임이 무너진다.
- **소리도 대상의 것을 그대로 듣는다** (3-7). 화면만 넘겨받고 소리는 자기 자리 기준으로 들으면, 보이는 것과 들리는 것이 어긋나 관전이 오히려 혼란스러워진다.

### 3-7. 음성 채팅
**텍스트 채팅은 없다.** 모든 대화는 음성으로 한다.

**생존자 — 거리 기반 음성**
- 살아있는 퇴마사끼리 **가까울수록 잘 들리고 멀어질수록 작아진다.**
- 탐지 결과가 본인에게만 보이므로(3-2), **알아낸 것을 말로 전해야 한다.** 거리 감쇠가 있으므로 "정보를 전하려면 위험을 무릅쓰고 가까이 가야 한다" — 이것이 퇴마사 쪽 핵심 긴장이다.
- 저택 반대편에 있으면 아무리 소리쳐도 안 들린다. 흩어질수록 정보가 고립된다.

⚠️ **귀신은 말할 수 없다.** 거리 기반 음성에서 귀신이 소리를 내면 **그 순간 위치가 그대로 드러난다.** 투명 처리의 의미가 통째로 사라지므로 마이크를 열어주지 않는다.
- 대신 **귀신은 들을 수 있다.** 영혼으로 다가가 퇴마사들의 대화를 엿듣는 것이 정찰 수단이 된다 — 숨어서 듣는 쪽이 이 게임의 귀신답다.

**사망자 — 사망자 전용 음성**
- 사망한 퇴마사끼리만 대화한다. **살아있는 사람에게는 들리지 않으므로** 정보가 샐 여지가 없다.
- 사망자는 관전 중인 생존자의 **음성과 그 생존자가 듣는 소리를 똑같이 듣는다.** 즉 사망자의 귀는 관전 대상의 자리에 있다.
- 관전 대상을 바꾸면 들리는 소리도 함께 바뀐다.

## 4. 게임 흐름도 (접속 → 종료 → 대기방 복귀)

```
[1] 접속 / 방 개설
      │  방장: 방 이름·닉네임·인원제한·비밀번호(선택) 설정 → 방 생성
      │  대기방(로비) 개설, 다른 플레이어 참가
      ▼
[2] 대기방 (게임 설정)
      │  방장이 밸런스 파라미터 조절 (아래 6번 항목)
      │  귀신/퇴마사 역할 배정, 전원 준비 → 방장 시작
      ▼
[3] 은신 단계 (기본 30초, 설정 가능)
      │  귀신: 숨을 곳을 정함
      │  첫 은신 → 퇴마사는 대기지점에 묶임
      │  재은신   → 퇴마사는 자유롭게 움직인다. 대신 도구가 무효화돼 있다
      │  은신 시간 종료 → 귀신 본체 고정(이동 불가), 조사 시작
      ▼
[4] 조사 단계 (제한시간, 기본 설정값)
      │  귀신: 본체/영혼 분리 → 영혼 이동 → 공포스킬로 게이지 충전 (반복 가능)
      │  퇴마사: 도구 수집(최대 4개 소지) → 사용/탐지 → 제단 활용
      │
      ├──[탐지 성공 · 1~2번째]──▶ 약점 공개 + 귀신 재은신 → [3]으로 되돌아감
      │                            ※ 조사 시간은 다음 회차에 <b>가득 채워져</b> 다시 시작
      │
      ├──[탐지 성공 · 3번째]─────────────────────▶ 퇴마사 승리 → [6]
      │
      ├──[제단에 올바른 도구 3종]────────────────▶ 퇴마사 승리 → [6]
      │
      ├──[제단에 틀린 도구 3종]──▶ 무작위 1명 사망 (계속, 도구는 회수 가능)
      │
      └──[현실화 게이지 100% OR 조사 제한시간 종료]──▶ [5] 사냥 단계
      ▼
[5] 사냥 단계 (기본 60초, 설정 가능)
      │  귀신 현실화(투명 해제), 달리면 퇴마사의 2배
      │  ├──[사냥 시간 내 퇴마사 전원 사망]──▶ 귀신 승리
      │  └──[사냥 시간 종료 시 생존자 존재]──▶ 퇴마사 승리
      ▼
[6] 게임 종료
      │  승패 결과 표시
      ▼
[7] 대기방 복귀
      │  전원 로비로 이동, 재시작 or 방 나가기
```

## 5. 승리 조건

### 퇴마사 승리
- **탐지로 약점 3종을 모두 밝혀냄** (조사 단계를 세 번 성공). **또는**
- 귀신의 약점에 맞는 도구 3종을 제단에 올바르게 헌납. **또는**
- 사냥 시간이 종료될 때까지 **1명 이상 생존**.

### 귀신 승리
- 사냥 단계 진입(현실화 게이지 100% 또는 **조사** 제한시간 종료) 후, **사냥 시간 내 퇴마사 전원 사망**.

### 진영별 종료 트리거 요약

| 트리거 | 결과 |
|---|---|
| 탐지 성공 (1~2번째) | 약점 공개 + 은신 단계로 복귀, 조사 시간 회복 |
| 탐지 성공 (3번째) | 퇴마사 승리 |
| 제단에 올바른 도구 3종 헌납 | 퇴마사 승리 |
| 제단에 틀린 도구 3종 헌납 | 무작위 1명 사망 (게임 계속, 도구 회수 가능) |
| 현실화 게이지 100% | 사냥 단계 진입 |
| **조사** 제한시간 종료 | 사냥 단계 진입 |
| 사냥 중 퇴마사 전원 사망 | 귀신 승리 |
| 사냥 시간 종료 & 생존자 존재 | 퇴마사 승리 |

## 6. 밸런스 파라미터 (대기방에서 방장이 설정)

| 파라미터 | 설명 | 예시 기본값 |
|---|---|---|
| a. 귀신 은신 시간 | 게임 시작 시 귀신이 숨을 시간 | 30초 |
| b. 조사 시간 | **조사 단계 1회분** 제한시간. 탐지에 성공할 때마다 가득 회복된다 | 2분 |
| c. 공포스킬 쿨타임 | 귀신 공포스킬 재사용 대기시간 | 30초 |
| d. 재은신 시간 | 귀신이 탐지된 후 다시 숨을 수 있는 시간 (= 도구 무효화 시간) | 15초 |
| e. 도구 탐지 사거리 | 화면 안에 들어와도 이 거리를 넘으면 실패 | 50m |
| f. 흡수 1회당 게이지 | 공포스킬 성공 시 현실화 게이지 상승량 | 20% |
| g. 도구 쿨타임 | 도구 사용 후 재사용 대기시간. 그때 들고 있던 도구 전부에 걸린다 | 20초 |
| h. 사냥 시간 | 사냥 단계 지속 시간 | 60초 |

**c와 f가 함께 현실화 속도를 결정한다.** 기본값(쿨타임 30초 / 1회 20%)이면 5번 성공해야 하므로 **최소 2분**이 걸린다.

**b는 이제 판 전체가 아니라 회차 길이다.** 탐지에 성공할 때마다 회복되므로, 퇴마사가 잘하면 게임이 길어지고 못하면 b 한 번 만에 사냥으로 넘어간다. 즉 **b는 "몇 분짜리 게임인가"가 아니라 "한 번의 기회가 얼마나 긴가"** 를 정한다. 게이지(c·f)와 경주하는 구조라 셋을 함께 보고 조정할 것.

**g는 팀 전체의 탐지 빈도를 정한다.** 도구가 종류당 하나뿐이고 쿨타임이 손에 든 것 전부에 걸리므로, 값이 크면 "나눠 들기"가 강제되고 작으면 한 사람이 다 들고 다녀도 된다.

기본값은 전부 **플레이테스트 전 임시값**이다. 실제로 해보고 조정할 것.

### 방 개설 시 고정 설정
- 방 이름
- 방장 닉네임
- 인원 제한
- 비밀번호 (선택)

### 참고: 시나리오상 고정 수치
방장이 조절할 수 없는 값들. 코드 상수로 두고 플레이테스트로만 조정한다.

| 항목 | 값 | 비고 |
|---|---|---|
| 최대 인원 | **5명** | 귀신 1 + 퇴마사 4. 방장은 이 이하로만 설정 가능 |
| 도구 종류 | **6종** | 카메라, 십자가, 성서, 성수, 탐지기, 향초 |
| 약점 도구 | **3종** | |
| 퇴마사 동시 소지 도구 | **최대 4개** | 고정 4칸, 1~4로 전환 |
| 맵에 놓이는 도구 | **종류당 1개 (총 6개)** | 소모되지 않고 쿨타임으로 재사용 |
| 퇴마사 이동속도 | **4 m/s** | 임시값 |
| 영혼 이동속도 | **4 m/s** | 퇴마사와 동일. 벽에 막히는 대신 속도 이점은 주지 않는다 |
| 사냥 시 귀신 이동속도 | 걷기 **4 m/s** / 달리기 **8 m/s** | 달릴 때 퇴마사의 2배 |
| 공포스킬 사거리 | **1.5m** | 근거리. 어몽어스의 칼처럼 바로 옆에 붙어야 발동 |
| 사냥 처형 쿨타임 | **3초** | 한 번 누를 때 한 명만 죽도록 짧게 |
| 탐지의 벽 통과 | **막힘** | 벽·닫힌 문 너머는 탐지되지 않는다. 안개·어둠은 판정과 무관 |

속도·사거리 수치는 전부 **임시값**이다. 실제로 플레이해보고 정한다.
